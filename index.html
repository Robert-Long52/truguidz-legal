TruHuntz

Flagship iOS app

Know where your scent is going before you climb the stand. Pick any pin and TruHuntz draws a scent cone from that exact spot using the wind forecast for that location.

  • Wind and scent cone from any pin, so you can plan a sit the night before
  • Home-screen and lock-screen widgets with the next eight hours of wind
  • Private pins for stands, trail cameras, rubs, scrapes and bedding
  • Topographic and satellite maps, with a dark interface for low light
  • Free to use, with an optional account that backs up your pins
  • SwiftUI
  • WidgetKit
  • Supabase
  • iOS 17+

TruKit

Developer starter kit

A SwiftUI + Supabase boilerplate for iOS. Skip the setup chores and start on the app only you can build.

  • Email and Sign in with Apple auth, with in-app account deletion built for App Review
  • Paywall with Stripe, StoreKit 2 or RevenueCat behind one protocol
  • Real-time map, Row Level Security and four Edge Functions, all documented
  • Demo mode that runs the whole app before you connect a backend

Under the hood

How the scent cone works.

This is the real geometry from TruHuntz, trimmed to the essentials. Move the wind and watch each line of Swift take effect. Hover a value to find the code behind it.

ScentCone.swiftTruHuntz · Swift
// An ESTIMATE of where scent travels, drawn downwind.// Wind direction is where the wind comes FROM, so// scent drifts toward the opposite bearing.struct ScentCone {    let origin: CLLocationCoordinate2D    let windFromDeg: Double    let windSpeedMph: Double     // Under ~2 mph there's no steady wind to carry scent.    var isCalm: Bool { windSpeedMph < 2 }     var downwindBearing: Double {        (windFromDeg + 180).truncatingRemainder(dividingBy: 360)    }     // Stronger wind carries scent farther.    var lengthYards: Double {        isCalm ? 65 : min(100 + 25 * windSpeedMph, 500)    }     var halfAngleDeg: Double {        windSpeedMph >= 12 ? 15 : 22.5    }     // Closed polygon: origin -> arc across the plume -> origin    var ring: [CLLocationCoordinate2D] {        if isCalm { return /* full circle */ }        let start = downwindBearing - halfAngleDeg        let end   = downwindBearing + halfAngleDeg        let arc = stride(from: start, through: end, by: 3).map {            Self.destination(from: origin, bearing: $0, meters: lengthMeters)        }        return [origin] + arc + [origin]    }}

An estimate based on wind alone. Terrain and thermals change the real picture, and the app says so wherever it shows the cone.
